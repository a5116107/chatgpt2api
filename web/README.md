# ChatGPT2API 工作空间前端

## 构建与校验

- 运行环境：Node.js 20.9 或更高版本；使用 npm ci 按锁文件安装。
- npm run dev：本地 Next.js 开发服务器。
- npm run check：类型检查、零警告 ESLint、格式校验、导航与轮询单元测试。
- npm run test:e2e：浏览器交互测试；接口被 fixtures 完整拦截，不触发真实业务。
- npm run build：在 Linux 构建环境生成 out/ 静态资源；TypeScript 错误与错误的分段资源路径均会阻止发布。Windows 可本地开发，但当前框架在 Windows 导出分段资源存在路径缺陷，生产产物由隔离 Linux 原生工作区生成，不通过复制或改名修补。
- 生产产物验收：构建后，设置 PLAYWRIGHT_STATIC=1，再运行 npx playwright test。
- 测试产物统一写入项目 artifacts/frontend/；复跑覆盖旧的截图与 trace。

## 环境与权限

NEXT_PUBLIC_API_URL 默认为生产同源；开发环境默认为本机 8000 端口。浏览器测试显式覆盖为空串。NEXT_PUBLIC_APP_VERSION 保留既有版本标识。仅使用 NEXT_PUBLIC_ 前缀的公开配置，任何管理密钥均不写入构建环境或源码。

管理员具有 13 个入口；普通用户仅展示对话、图像、视频创作。导航、功能搜索、页面说明和入口权限都由 src/lib/navigation.ts 维护。服务端仍负责实际接口鉴权，隐藏导航不替代后端权限检查。

## 交互与维护约定

- 全站使用 globals.css 的语义颜色、统一组件和明暗主题，不再维护旧 TopNav 或全局深色强制覆盖。
- Ctrl/Cmd+K 搜索功能；方向键选择、回车进入、Esc 关闭。移动端导航选择后自动收起。
- 请求失败显示可重试状态，认证网络失败保留本地登录信息；401/403 才清理失效会话。
- 注册高级取信设置按需展开；折叠不清空草稿，不自动保存配置。
- 危险批量操作须可取消并恢复焦点。第三方画布传递密钥前需显式确认。
- 账户进度采用串行请求与取消信号，离开页面即停止前端轮询；任务列表查询支持取消与 20 秒超时，不伪造后台完成进度。
- 视频预览按需携带 Bearer 鉴权获取文件，不把密钥放入 URL；支持取消、失败重试、下载与释放，离开页面即终止请求并回收 Blob URL。历史文件失效不自动清空登录。
- 对话与图像页采用专注式创作布局：仅保留当前功能的历史侧栏，全局功能通过导航抽屉访问，消息区独立滚动，输入区跟随可视窗口与软键盘高度。
- 对话使用可取消的 SSE 增量响应，支持 Markdown、表格、代码、复制、草稿切换、重命名、删除和携带鉴权的导出；失败保留输入和已接收内容，不伪报回复成功。
- 图像页保留本地历史、队列、参考图编辑、尺寸/质量/数量设置、单张重试、超时续等和下载。上游 HTML 错误仅作为折叠纯文本展示，图像对象 URL 在切换历史或离页时回收。
- 浏览器回归覆盖管理员入口、用户权限、键盘、失败重试、筛选、空态、导入对话框、取消删除、响应式及 WCAG A/AA 自动检查。

## 前端发布边界

本轮发布范围包括前端、会话持久化去重，以及用户后续批准的账号状态检测、代理接入、注册调度和对话/图像运行修复。完整请求上下文继续交给上游，历史只追加新增消息，不执行旧历史数据迁移。

生产构建使用 Linux 生成静态资源；后端与静态资源以当前运行镜像为基底制作候选镜像，白名单不包含账号、邮箱源、密钥、运行配置及业务数据。切换前检查在途任务、源码基线和运行参数，执行隔离镜像回归，保留旧镜像、源码及私密账号快照。发布后分别核对登录凭据、代理绑定、业务配置、运行参数及源码哈希；回滚恢复旧镜像与源文件，不覆盖业务数据。具体版本和真实业务阻塞以 docs/project/STATE.md 为准。

验收中的业务接口均为隔离样本；界面测试通过不表示第三方生成服务或真实注册链路已经恢复。
